# Explain on request

**Type:** AFK

## What to build

Default UI is the command only. `-e`/`--explain` includes the explanation. `?` at the confirm prompt shows details, then returns to `Run?`.

## Acceptance criteria

- [ ] Default preview is the command with no essay
- [ ] `interpret -e …` / `@ -e …` shows an explanation
- [ ] `?` at confirm shows details and returns to the confirm prompt
